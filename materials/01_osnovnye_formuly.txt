СБОРНИК ФОРМУЛ
Определение момента инерции твёрдых тел
методом крутильных колебаний
1. Основные определения момента инерции
1.1.  Момент инерции твёрдого тела при непрерывном распределении масс
I = ∫ ρ r² dV
Пояснение: ρ — плотность вещества в элементе объёма dV; r — расстояние элемента до оси вращения. Формула показывает, что момент инерции — мера инертности тела при вращательном движении.
1.2.  Момент инерции системы материальных точек (дискретная форма)
I = Σ rᵢ² Δmᵢ
Пояснение: сумма берётся по всем элементам массы Δmᵢ, находящимся на расстоянии rᵢ от оси вращения.
2. Моменты инерции тел правильной формы
2.1.  Материальная точка массы m на расстоянии R от оси:
I = m R²
2.2.  Тонкий стержень массы m, длины l (ось через центр, перпендикулярно стержню):
I = (1/12) m l²
2.3.  Тонкий стержень (ось через конец, перпендикулярно стержню):
I = (1/3) m l²
2.4.  Диск (цилиндр) массы m, радиуса R (ось симметрии — ось цилиндра):
I = (1/2) m R²
2.5.  Куб массы m, ребра a (центральная главная ось, параллельная ребру):
I = (1/6) m a²
Пояснение: эта формула используется как эталон для определения момента инерции рамки в лабораторной работе.
2.6.  Шар массы m, радиуса R (ось через центр):
I = (2/5) m R²
3. Момент инерции относительно произвольной оси. Тензор инерции
Пусть оси координат Ox, Oy, Oz проходят через точку O, а ось вращения OA образует с ними углы α, β, γ.
3.1.  Вспомогательные геометрические соотношения:
R² = x² + y² + z²
OB = x cos α + y cos β + z cos γ
cos²α + cos²β + cos²γ = 1
3.2.  Моменты инерции относительно осей координат:
Iₓ = Σ Δmᵢ (y² + z²)
Iᵧ = Σ Δmᵢ (z² + x²)
Iz = Σ Δmᵢ (x² + y²)
3.3.  Центробежные моменты инерции:
Ixy = Σ Δmᵢ xy
Ixz = Σ Δmᵢ xz
Iyz = Σ Δmᵢ yz
Пояснение: понятие тензора инерции возникает, когда тело имеет произвольную форму или неоднородное распределение масс, и момент инерции зависит от направления оси вращения.
3.4.  Общее выражение момента инерции относительно произвольной оси (через тензор инерции):
I = Iₓ cos²α + Iᵧ cos²β + Iz cos²γ
− 2 Iyz cos β cos γ − 2 Ixz cos α cos γ − 2 Ixy cos α cos β
Пояснение: это формула (3) из методички. Она связывает момент инерции относительно любой оси, проходящей через точку O, с компонентами тензора инерции.
4. Главные и центральные оси инерции
4.1.  Условие главных осей (центробежные моменты равны нулю):
Ixy = Ixz = Iyz = 0
Пояснение: главные оси инерции — три взаимно перпендикулярные оси, для которых центробежные моменты инерции равны нулю. Центральные главные оси — главные оси, проходящие через центр масс. Для однородных симметричных тел они совпадают с осями симметрии тела.
4.2.  Момент инерции в главных осях (формула (4)):
I = Iₓ cos²α + Iᵧ cos²β + Iz cos²γ
Пояснение: когда оси координат совпадают с главными осями инерции, центробежные члены исчезают, и момент инерции определяется только тремя главными моментами Iₓ, Iᵧ, Iz.
5. Эллипсоид инерции
5.1.  Длины полуосей эллипсоида инерции (в произвольном масштабе):
lᵢ = 1 / √Iᵢ
Пояснение: если от начала координат по всем направлениям откладывать отрезки длиной 1/√I, концы образуют эллипсоид инерции. Его оси совпадают с главными осями инерции. Эллипсоид относительно центра масс называется центральным.
6. Крутильные колебания
6.1.  Период крутильных колебаний (формула (5)):
T = 2π √(I / κ)
Пояснение: I — момент инерции тела относительно оси подвеса; κ — модуль кручения нити (проволоки) подвеса. Формула лежит в основе экспериментального метода.
6.2.  Возвращающий момент при малых углах закручивания:
M = −κ φ
Пояснение: φ — угол закручивания. Момент пропорционален углу и направлен против отклонения (закон Гука для кручения).
6.3.  Условие малости колебаний
Пояснение: формула периода справедлива при малых углах закручивания, когда деформация нити упруга и момент сил пропорционален углу. При больших амплитудах появляются нелинейные эффекты, и период начинает зависеть от амплитуды.
7. Экспериментальное определение момента инерции
7.1.  Период колебаний свободной (пустой) рамки:
Tₚ = 2π √(Iₚ / κ)
7.2.  Период колебаний рамки с кубом (или другим телом):
Tₖₚ = 2π √((Iₖ + Iₚ) / κ)
7.3.  Момент инерции пустой рамки (через известный момент инерции куба Iₖ):
Iₚ = Iₖ · (Tₚ² / (Tₖₚ² − Tₚ²))
Пояснение: куб с известным теоретическим моментом инерции Iₖ = (1/6) m a² служит эталоном для нахождения Iₚ.
7.4.  Момент инерции произвольного тела (через момент инерции рамки):
Iₜ = Iₚ · ((Tₜₚ² − Tₚ²) / Tₚ²)
Пояснение: Tₜₚ — период колебаний рамки с исследуемым телом. Формула позволяет найти момент инерции любого тела, закреплённого в рамке.
8. Связь момента инерции с кинетической энергией и динамикой вращения
8.1.  Кинетическая энергия вращательного движения:
Eₖ = (1/2) I ω²
Пояснение: ω — угловая скорость. Аналог формулы кинетической энергии поступательного движения (1/2) m v².
8.2.  Основное уравнение динамики вращательного движения:
M = I ε
Пояснение: M — суммарный момент внешних сил относительно оси; ε = dω/dt — угловое ускорение. Аналог второго закона Ньютона F = m a.
8.3.  Момент импульса (угловой момент) твёрдого тела относительно оси:
L = I ω
Пояснение: аналог линейного импульса p = m v. При отсутствии внешних моментов момент импульса сохраняется.
9. Теорема Штейнера (параллельных осей)
9.1.  Связь момента инерции относительно произвольной оси с моментом относительно параллельной оси через центр масс:
I = Icm + m d²
Пояснение: Icm — момент инерции относительно оси, проходящей через центр масс; m — масса тела; d — расстояние между параллельными осями.
9.2.  Пример: стержень (ось через конец из оси через центр):
I_конец = (1/12) m l² + m (l/2)² = (1/3) m l²
Пояснение: теорема Штейнера позволяет быстро переходить от момента инерции относительно центра масс к моменту относительно любой параллельной оси.
10. Тензор инерции в главных осях
10.1.  В главных осях тензор инерции диагонален:
I = diag(Iₓ, Iᵧ, Iz)
то есть матрица тензора имеет вид:
⎛ Iₓ  0   0  ⎞
⎜ 0   Iᵧ  0  ⎟
⎝ 0   0   Iz ⎠
Пояснение: в главных осях все центробежные моменты равны нулю, и тензор полностью определяется тремя главными моментами инерции.
11. Погрешности измерений
11.1.  Период по результатам измерения времени t за n колебаний:
T = t / n
Пояснение: для уменьшения погрешности рекомендуется измерять время не менее 10 полных колебаний.
11.2.  Относительная погрешность момента инерции (косвенные измерения):
δI / I ≈ 2 δT / T  (+ вклад погрешностей κ или эталонного I)
Пояснение: поскольку I ∝ T², относительная погрешность момента инерции примерно в два раза больше относительной погрешности периода. Необходимо также учитывать погрешность определения модуля кручения κ или эталонного момента инерции.
12. Проверка адекватности модели
Если экспериментальные моменты инерции для разных осей согласуются с теоретическими (вычисленными по формуле (4) через направляющие косинусы), то эллипсоид инерции правильно описывает инерционные свойства тела. Расхождение не должно превышать суммарную погрешность измерений.
