ТЕОРИЯ
Определение момента инерции твёрдых тел методом крутильных колебаний
1. Момент инерции твёрдого тела
Момент инерции — мера инертности тела при вращательном движении. При непрерывном распределении масс:
I = ∫ ρ r² dV
где ρ — плотность вещества в элементе объёма dV, r — расстояние от элемента до оси вращения.
Для системы материальных точек:
I = Σ mᵢ rᵢ²
2. Моменты инерции тел правильной формы
• Материальная точка массы m на расстоянии R от оси: I = m R²
• Тонкий стержень массы m, длины l (ось через центр, перпендикулярно стержню): I = (1/12) m l²
• Тонкий стержень (ось через конец): I = (1/3) m l²
• Диск (цилиндр) массы m, радиуса R (ось симметрии): I = (1/2) m R²
• Куб массы m, ребра a (центральная главная ось, параллельная ребру): I = (1/6) m a²
• Шар массы m, радиуса R (ось через центр): I = (2/5) m R²
3. Момент инерции относительно произвольной оси. Тензор инерции
Пусть оси координат Ox, Oy, Oz проходят через точку O, а ось вращения OA образует с ними углы α, β, γ. Тогда:
I = Iₓ cos²α + Iᵧ cos²β + I_z cos²γ
− 2 Iyz cos β cos γ − 2 Ixz cos α cos γ − 2 Ixy cos α cos β
где осевые моменты инерции:
Iₓ = Σ mᵢ (yᵢ² + zᵢ²),   Iᵧ = Σ mᵢ (zᵢ² + xᵢ²),   I_z = Σ mᵢ (xᵢ² + yᵢ²)
и центробежные моменты инерции:
Ixy = Σ mᵢ xᵢ yᵢ,   Ixz = Σ mᵢ xᵢ zᵢ,   Iyz = Σ mᵢ yᵢ zᵢ
Понятие тензора инерции возникает, когда тело имеет произвольную форму или неоднородное распределение масс, и момент инерции зависит от направления оси вращения.
4. Главные и центральные оси инерции
Главные оси инерции — три взаимно перпендикулярные оси, для которых центробежные моменты инерции равны нулю:
Ixy = Ixz = Iyz = 0
Центральные главные оси — главные оси, проходящие через центр масс. Для однородных симметричных тел они совпадают с осями симметрии тела.
5. Эллипсоид инерции
Если от начала координат по всем направлениям откладывать отрезки длиной 1/√I, концы образуют эллипсоид инерции. Его оси совпадают с главными осями инерции. Эллипсоид относительно центра масс называется центральным.
6. Крутильные колебания
Период крутильных колебаний:
T = 2π √(I / κ)
где I — момент инерции тела, κ — модуль кручения нити подвеса.
7. Определение момента инерции куба
Теоретический момент инерции куба массы m с ребром a относительно центральной главной оси, параллельной ребру:
I = (1/6) m a²
Эта величина используется как эталон в экспериментальной формуле для нахождения момента инерции рамки.
8. Длины осей эллипсоида инерции
Длины полуосей эллипсоида инерции:
lᵢ = 1 / √Iᵢ
где Iᵢ — момент инерции относительно соответствующей главной оси. Построение — в произвольном масштабе.
9. Связь момента инерции с кинетической энергией и динамикой вращения
Кинетическая энергия вращательного движения:
Eₖ = (1/2) I ω²
где ω — угловая скорость.
Основное уравнение динамики вращательного движения:
M = I ε
где M — суммарный момент внешних сил относительно оси, ε = dω/dt — угловое ускорение.
10. Момент импульса
Момент импульса твёрдого тела относительно оси:
L = I ω
11. Теорема Штейнера
Момент инерции относительно произвольной оси связан с моментом инерции относительно параллельной оси, проходящей через центр масс:
I = Icm + m d²
где m — масса тела, d — расстояние между осями.
Пример для стержня (переход от оси через центр к оси через конец):
Iконец = (1/12) m l² + m (l/2)² = (1/3) m l²
12. Тензор инерции и эллипсоид инерции
В главных осях тензор инерции диагонален:
⎛ Iₓ   0    0  ⎞
⎜  0   Iᵧ   0  ⎟
⎝  0    0   I_z ⎠
В главных осях все центробежные моменты равны нулю, и тензор полностью определяется тремя главными моментами инерции Iₓ, Iᵧ, Iz.
13. Крутильный маятник как колебательная система
При малых углах закручивания возвращающий момент:
M = −κ φ
14. Условие малости колебаний
Формула периода справедлива при малых углах закручивания, когда деформация нити упруга и момент сил пропорционален углу. При больших амплитудах появляются нелинейные эффекты, и период начинает зависеть от амплитуды.
15. Погрешности при измерении периода
Период:
T = t / n
где t — время, измеренное за n полных колебаний. Для уменьшения погрешности рекомендуется брать n ≥ 10.
16. Погрешность косвенных измерений момента инерции
Относительная погрешность момента инерции (поскольку I ∝ T²):
δI / I ≈ 2 (δT / T)
Необходимо также учитывать погрешность определения модуля кручения κ (или эталонного момента инерции куба).
17. Проверка адекватности модели по эллипсоиду инерции
Если экспериментальные моменты инерции для разных осей согласуются с теоретическими (по формуле I = Iₓ cos²α + Iᵧ cos²β + Iz cos²γ через направляющие косинусы), то эллипсоид инерции правильно описывает инерционные свойства тела. Расхождение не должно превышать суммарную погрешность измерений.
