ОПРЕДЕЛЕНИЕ МОМЕНТА ИНЕРЦИИ ТВЕРДЫХ ТЕЛ МЕТОДОМ КРУТИЛЬНЫХ КОЛЕБАНИЙ
ПЕРЕД НАЧАЛОМ РАБОТЫ НЕОБХОДИМО ПРОВЕРИТЬ НАДЁЖНОСТЬ ЗАЗЕМЛЕНИЯ
КРАТКАЯ ТЕОРИЯ
Одной из основных характеристик твёрдого тела является его момент инерции — мера инертности при вращательном движении. Момент инерции твёрдого тела при непрерывном распределении масс определяется как
I = ∫ ρ r² dV                                              (1)
где ρ — плотность вещества в элементе объёма dV, находящемся на расстоянии r от оси вращения [1].
Для тел правильной формы моменты инерции относительно оси симметрии можно вычислить с помощью формулы (1). Однако при произвольной форме поверхности тела и неоднородном распределении масс аналитический расчёт момента инерции часто превращается в чрезвычайно громоздкую задачу. В этом случае можно использовать экспериментальный метод определения момента инерции.
Установим зависимость между величинами моментов инерции тела относительно осей вращения, пересекающихся в одной точке. С этой целью определим момент инерции тела относительно некоторой оси вращения OA.
За начало координат выберем произвольную точку O в твёрдом теле на оси вращения (рис. 1). С произвольно направленными осями координат ось вращения образует углы α, β, γ. Для некоторого элемента тела массой Δmᵢ (x, y, z) можем записать [2]:
I = Σ rᵢ² Δmᵢ                                              (2)
Учтём, что
R² = x² + y² + z²,    OB = x cos α + y cos β + z cos γ
и    cos²α + cos²β + cos²γ = 1
и получим
I = Σ Δmᵢ [(x² + y² + z²)(cos²α + cos²β + cos²γ) − (x cos α + y cos β + z cos γ)²] =
= cos²α Σ Δmᵢ (y² + z²) + cos²β Σ Δmᵢ (x² + z²) + cos²γ Σ Δmᵢ (x² + y²) −
− 2 cos β cos γ Σ Δmᵢ yz − 2 cos α cos γ Σ Δmᵢ xz − 2 cos α cos β Σ Δmᵢ xy
Выражения
Iₓ = Σ Δmᵢ (y² + z²),    Iᵧ = Σ Δmᵢ (z² + x²),    Iz= Σ Δmᵢ (x² + y²)
представляют собой моменты инерции тела относительно осей координат.
Выражения
Ixy = Σ Δmᵢ xy;    Ixz = Σ Δmᵢ xz;    Iyz = Σ Δmᵢ yz
называются центробежными моментами инерции.
Выражение (2) можем переписать в виде:
I = Iₓ cos²α + Iᵧ cos²β + Iz cos²γ − 2 Iyz cos β cos γ − 2 Ixz cos α cos γ − 2 Ixy cos α cos β  (3)
Рассмотрим геометрическую интерпретацию изменения величины момента инерции тела при изменении направления оси вращения, проходящей через точку O. Для этого отложим от начала координат по всем осям в произвольном, но в одном масштабе отрезки, длина которых равна 1/√I , где I — момент инерции тела относительно данной оси. Концы этих отрезков находятся на поверхности эллипсоида, который называется эллипсоидом инерции относительно точки O. Оси эллипсоида называют главными осями инерции в этой точке.
Можно показать, что в случае, когда оси координат совпадают с осями инерции, получается
I = Iₓ cos²α + Iᵧ cos²β + Iz cos²γ                                              (4)
В этом случае момент инерции I определяется тремя величинами Iₓ, Iᵧ, I_z.
Эллипсоид инерции относительно центра тяжести называется центральным, а его главные оси называются центральными главными осями инерции. Для однородных симметричных тел главные центральные оси инерции — оси симметрии тела.
Экспериментальное определение момента инерции производится при помощи формулы периода крутильных колебаний [1]:
T = 2π √(I / κ)                                              (5)
здесь I — момент инерции тела, κ — модуль кручения нити подвеса.
Для использования этой формулы необходимо предварительно определить модуль кручения κ.
ОПИСАНИЕ ЭКСПЕРИМЕНТАЛЬНОЙ УСТАНОВКИ
В качестве экспериментальной установки для определения моментов инерции тел используется крутильный маятник, который позволяет определять период крутильных колебаний. На рис. 2 показана схема крутильного маятника. На основании 2, которое имеет четыре регулируемые по высоте ножки, укреплён миллисекундомер 1. К основанию прикреплена колонна 3 с тремя кронштейнами 4, 5, 6. Верхний и нижний кронштейны имеют зажимы для закрепления стальной проволоки, на которой подвешена рамка 7. На среднем кронштейне укреплены фотоэлектрический датчик 9, электромагнит 10 и угловая шкала 11. Электромагнит 10 может изменять положение на плите, а его положение относительно фотоэлектрического датчика определяется по угловой шкале.
Конструкция рамки позволяет закреплять различные грузы 12 при помощи подвижной балки, которая перемещается по направляющим между неподвижными балками. Балка устанавливается путём затягивания гаек на зажимных втулках, помещённых на подвижной балке.

3: колонна				10: электромагнит
4,5,6: кранштейны			11: угольная шкала

ОПРЕДЕЛЕНИЕ ПЕРИОДА КРУТИЛЬНЫХ КОЛЕБАНИЙ
–	закрепить надёжно исследуемый груз в рамке прибора;
–	установить электромагнит в заданном положении, зафиксировать его гайкой;
–	нажать кнопку «СЕТЬ» на лицевой панели миллисекундомера. При этом наблюдается свечение цифровых индикаторов и включается ток в обмотке электромагнита;
–	поворачивая рамку прибора, приблизить её стрелку к электромагниту таким образом, чтобы он фиксировал положение рамки;
–	нажать кнопку «ПУСК», запуск секундомера происходит в момент пересечения светового луча рамкой;
–	после набора измерителем не менее 10 крутильных колебаний нажать кнопку «СТОП», прибор показывает число полных колебаний;
–	произвести отсчёт времени и числа колебаний;
–	нажать кнопку «СБРОС». Прибор готов к новому циклу измерений.
ХОД РАБОТЫ
1.	Рассчитать теоретически момент инерции куба относительно одной его центральной главной оси для заданных значений m — массы куба и a — ребра куба.
2.	Определить период крутильных колебаний пустой рамки Tₚ.
3.	Закрепить куб в рамке и определить период его крутильных колебаний Tₖₚ — период колебаний куба в рамке.
4.	Iₖ — момент инерции куба из п. 1.
Tₚ = 2π √(Iₚ / κ)  — период колебаний свободной рамки.
Tₖₚ = 2π √((Iₖ + Iₚ) / κ)  — период колебаний рамки с кубом.
Отсюда определяем Iₚ:
Iₚ = Iₖ · (Tₚ² / (Tₖₚ² − Tₚ²))
Момент инерции любого тела определяется по формуле:
Iₜ = Iₚ · ((Tₜₚ² − Tₚ²) / Tₚ²)
5.	Вставить в рамку прибора один из параллелепипедов и определить период его крутильных колебаний относительно трёх центральных осей.
6.	Рассчитать по формуле (5) для данных значений T и κ величины Iₓ, Iᵧ, I_z.
7.	Закрепить параллелепипед в рамке в разных положениях и определить его моменты инерции относительно разных осей (относительно диагоналей и т.д.).
8.	Провести расчёт этих моментов инерции относительно разных осей с помощью формулы (4) и сопоставить их значения с результатом, полученным экспериментально в п. 7.
9.	Провести аналогичные измерения для второго параллелепипеда.
10.	Рассчитать длину осей эллипсоида инерции для всех исследованных тел в произвольном масштабе по формуле 1/√I.
